# WSGI server. Named by Procfile, by deploy.ps1's systemd restart, and by three
# docstrings under src/api/ -- and until now by no requirements file, so the
# documented production runtime was never a declared dependency (it is absent
# from this worktree's .venv). The floor is not cosmetic, for two reasons.
# Security: gunicorn binds a public listener, and releases before 23.0 carry
# known HTTP request-smuggling bugs (CVE-2024-1135, fixed in 22.0;
# CVE-2024-6827, fixed in 23.0). Held by tests/test_npc_chat_turn_budget.py.
# Correctness: app.py's _register_request_limits only reads a chunked body
# when the server has set `wsgi.input_terminated` in the environ, which
# gunicorn has done since 20.1.0 -- under an older one an oversized chunked
# body is silently truncated at the cap and answered 400.
#
# The ceiling is the next major. The old `<26` existed only because gunicorn
# 26.0 removed the eventlet worker the unit used to run (#653); the unit now
# runs gthread (deploy/heart-of-virtue.service), which 26.x still ships. It is
# bounded rather than open because an unbounded floor-only range is how #653
# happened: re-verify the unit's worker on each new major before lifting it.
gunicorn>=23.0,<27

# No eventlet. The unit ran `--worker-class eventlet` until 2026-09-26, and
# its monkey-patching is what broke two things: on Python 3.13 asyncio database
# calls never completed under it (#726), and src/api/db.py's one-loop client --
# the fix for concurrent requests cancelling each other's queries -- cannot
# hand work between loops under a patched hub. gthread serves requests on real
# OS threads, which is also what the threading locks in GameService and
# async_mode="threading" (src/api/app.py) were written for. Do not re-add it:
# tests/test_npc_chat_turn_budget.py fails if the unit names a patching worker.

# Pinned because _register_request_limits argues its correctness against a
# specific Werkzeug rather than against a documented contract: that
# LimitedStream.readall stops at the cap and RETURNS instead of raising, and
# that get_input_stream hands the app an empty stream when wsgi.input_terminated
# is absent. Both are internals. Flask 3.1.2 only requires >=3.1, which would
# let a 3.2 reshaping LimitedStream arrive with no one re-reading that function;
# ~= holds the minor. The claims in that docstring were checked against 3.1.8.
Werkzeug~=3.1.0
